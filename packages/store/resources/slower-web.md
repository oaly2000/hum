# The Slower Web — Hum Supply sample edition

## Build light

Render useful HTML on the server. Send JavaScript for the parts that need it.
Prefer a readable page to an empty loading shell.

## Go carefully

Cache anonymous public content. Keep sessions, orders, and permissions private.
Treat a payment return URL as a navigation event; confirm payment on the server.

## Ship something real

Build the app, run it from its output directory, and verify that private files
stay private. Keep durable data outside the build directory.

This sample is provided to exercise private digital delivery in the Hum demo store.
