# Interface Notes — Hum Supply sample edition

## Start with the browser

Use real links for navigation. Use forms for submissions. Label every input.
Show errors close to the action and preserve a useful route back.

## Add interaction deliberately

Introduce an island for a preview or a small editor. Keep request-specific data
in props. Use shared signals when two UI roots need the same value.

## Remember the edges

Check keyboard focus, narrow screens, pending states, failed requests, and a
JavaScript-disabled browser. A working interface includes its recovery paths.

This sample is provided to exercise private digital delivery in the Hum demo store.
